## 1.1.0

- Works in existing worlds: the first time a world loads with the mod, the server adds the stones it's missing (one of each god's in land already explored, on open ground away from players' buildings and the game's own places; the rest in unexplored land). Done once per world; `PlaceInExistingWorlds` turns it off, `ssov_placestones` runs it by hand.
- README: says it works in new and existing worlds, and that it needs Jötunn.

## 1.0.0

- First release: sixteen standing stones of the Norse gods (path, blessing, bargain and power stones), Hel's mark, daily powers on H, hints towards unfound stones, and the rune altar. English and Turkish.
